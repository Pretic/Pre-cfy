# cfy 综合订阅全链接去重设计

## 目标

在生成 `/etc/sing-box/all-url.txt` 时，对基础节点与 cfy 优选节点进行整行链接去重，避免完全相同的节点被重复发布到 v2rayN。

## 行为

- 先读取 `/etc/sing-box/url.txt`，再读取 `/etc/sing-box/cfy-url.txt`。
- 忽略空行和 Windows 行尾中的 `\r`。
- 以完整链接文本为键去重，第一次出现的链接和顺序保留，后续完全相同的链接跳过。
- 不按备注、IP 或其他局部字段合并不同链接，避免误删合法节点。
- 继续通过现有原子写入流程生成 `all-url.txt`、`all-sub.txt` 和对外的 `sub.txt`。

## 安全边界

本改动不解析或重写 VLESS/VMess 内容，不改变 UUID、端口、Host、SNI、WebSocket Path、TLS、隧道域名或候选 IP。Sing-box 基础节点优先于 cfy 结果，因此两边存在完全相同链接时保留基础节点中的第一次记录。

## 验证

- 使用临时基础文件和结果文件构造文件内重复、跨文件重复、空行和 CRLF 输入。
- 断言输出顺序为首次出现顺序，且每条完整链接只出现一次。
- 断言两个不同备注或不同字段的链接不会被合并。
- 运行现有候选规则测试、协议模板检查和 Bash 语法检查。
- 对比节点 URL 改写函数，确认连接参数处理未变化。
