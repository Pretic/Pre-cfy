# cfy 候选选择规则设计

## 目标

调整“云优选”候选整理逻辑，同时保持节点连接参数不变：

- IPv4 仍为默认选项，选择界面直接按 Enter 等同选择 `1`。
- 双栈和 IPv6 继续作为选项 `2`、`3`。
- 相同候选 IP 只保留第一次出现的记录及其运营商标签。
- 候选顺序严格沿用第三方页面顺序，IPv4 页面先于 IPv6 页面。
- 不修改 UUID、端口、Host、SNI、WebSocket path、TLS 或隧道配置。

## 实现

新增 `collect_unique_optimized_pairs` 纯整理函数。函数逐行读取现有的 `IP ISP` 临时文件，通过关联数组记录已出现的 IP；首次出现时追加到 `ip_list`、`isp_list`，重复时跳过。`get_all_optimized_ips` 继续负责下载和解析，只把原先的随机打乱步骤替换为调用该函数。

## 验证

- 使用固定夹具验证输出顺序与输入首次出现顺序一致。
- 验证重复 IP 只保留第一条运营商信息。
- 验证 Enter、`2`、`3` 分别得到 `ipv4`、`both`、`ipv6`。
- 运行现有协议模板测试和 Bash 语法检查。
- 对比改动，确认 VLESS URL 重写和隧道脚本未变化。
